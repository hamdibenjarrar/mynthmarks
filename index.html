The Evolution Score

    
A number from 0 to 1000 built from the last year of public activity. Every part runs from 0 to 1 and flattens out, so one huge week cannot max it. Steady work wins.

    
E = 1000 x (0.30 V + 0.20 C + 0.15 S + 0.15 M + 0.10 R + 0.10 L)

    

      
PartMeaningFormula

      
V volumehow much1 - e^(-contributions / 1000)

      
C consistencyhow oftenactive days / days

      
S streakright now1 - e^(-current streak / 30)

      
M momentumspeeding up or notmin(1, (last 90 day rate / earlier rate) / 2)

      
R reachwho cares1 - e^(-(stars + followers) / 200)

      
L rangehow wide1 - e^(-languages / 6)

    

    
Levels: Seed 0, Sprout 200, Grove 400, Canopy 600, Myth 800. See every part for any user at /api/json?source=live&metric=evolution&detail=1&user=NAME.
